## Solution
1. Log in to the AWS Management Console using the provided credentials and navigate to the **VPC** service.
2. Search `Subnets` in the search bar and click on it.
3. Click on the **Create subnet** button.
4. Select the default VPC from the **VPC** dropdown menu.
5. Enter `xfusion-subnet` in the **Subnet name** field.
6. Use the default values for **Availability Zone** and **IPv4 CIDR block**.
7. Determine the subnet **IPv4 CIDR block** based on the default VPC's CIDR block. 
8. Click on the **Create subnet** button to create the subnet.

## Notes
- A `subnet` is a range of IP addresses in your VPC which is used to divide the VPC into smaller segments and to group instances based on security and operational needs.
