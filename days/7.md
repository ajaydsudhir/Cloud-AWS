## Solution
1. Login to the AWS Management Console using the provided credentials.
2. Navigate to the EC2 Dashboard.
3. In the left-hand menu, click on "Instances" to view the list of EC2 instances.
4. Locate the instance named `nautilus-ec2` in the list.
5. Check the current instance type and ensure that the `Status check` is completed (not in `Initializing` state).
6. Select the `nautilus-ec2` instance by clicking the checkbox next to it.
7. Click on the "Instance State" dropdown menu and select "Stop" to stop the instance.
8. Wait for the instance to stop completely (the instance state should change to "stopped").
9. Once the instance is stopped, click on the "Actions" dropdown menu, then select "Instance Settings" and choose "Change Instance Type."
10. In the "Change Instance Type" dialog, select `t2.nano` from the list of available instance types.
11. Click the "Apply" button to save the changes.
12. After changing the instance type, click on the "Instance State" dropdown menu again and select "Start" to start the instance.
13. Wait for the instance to start completely (the instance state should change to "running").
