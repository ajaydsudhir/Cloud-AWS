## Solution
1. Login to the AWS Management Console using the provided credentials and navigate to the S3 service.
2. Create a new S3 bucket named `datacenter-web-40394967`.
3. Under the bucket properties, enable static website hosting and set `index.html` as the index document.
4. On the AWS-client host, run `aws s3 cp /root/index.html s3://datacenter-web-40394967/` to upload the `index.html` file to the S3 bucket.
5. Navigate to the bucket permissions and configure the bucket policy to allow public read access.
6. Add a bucket policy like the following to allow public access:
```json
{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Principal": "*",
            "Effect": "Allow",
            "Action": [
                "s3:GetObject"
            ],
            "Resource": [
                "arn:aws:s3:::datacenter-web-40394967/*"
            ]
        }
    ]
}
```
7. Verify that the website is accessible by visiting the S3 website URL, which can be found in the bucket properties under static website hosting.
