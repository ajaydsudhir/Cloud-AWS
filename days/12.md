## Solution
1. Log in to the AWS Management Console using the provided credentials.
2. Navigate to the EC2 service in the `us-east-1` region.
3. In the left-hand menu, click on "Volumes" under the "Elastic Block Store" section.
4. Locate the volume named `devops-volume` in the list of volumes.
5. Select the `devops-volume` volume by clicking the checkbox next to it.
6. Click on the "Actions" button and select "Attach Volume" from the dropdown menu.
7. In the "Attach Volume" dialog, select the instance named `devops-ec2` from the "Instance" dropdown menu.
8. Set the device name to `/dev/sdb` in the "Device" field.
9. Click the "Attach" button to attach the volume to the instance.

## Notes
- `Volume` is a block-level storage device that can be attached to an EC2 instance.
