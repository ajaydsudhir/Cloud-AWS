## Solution
1. Log in to the AWS Management Console using the provided credentials.
2. Navigate to the **EC2 Dashboard** in the `us-east-1` region.
3. In the left-hand menu, click on **Instances** to view the list of EC2 instances.
4. Locate the instance named `datacenter-ec2` in the list of instances.
5. Select the `datacenter-ec2` instance by clicking the checkbox next to it.
6. In the **Instance State** section of the instance details, click on **Actions**.
7. From the dropdown menu, select **Instance Settings** and then click on **Change Termination Protection**.
8. In the **Change Termination Protection** dialog box, check the box for **Enable Stop Protection**.
9. Click **Save** to apply the changes.

## Notes
- `Stop Protection` prevents the instance from being stopped accidentally.
