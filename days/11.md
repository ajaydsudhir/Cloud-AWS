## Solution
1. Log in to the AWS Management Console using the provided credentials.
2. Navigate to the EC2 Dashboard in the `us-east-1` region.
3. In the left-hand menu, click on "Instances" and locate the instance named `nautilus-ec2`.
4. Select the `nautilus-ec2` instance and click on the "Actions" button, then choose "Networking" and select "Attach Network Interface".
5. In the "Attach Network Interface" dialog, select the `nautilus-eni` network interface from the dropdown list.
6. Click the "Attach" button to attach the network interface to the instance.

## Notes
- `Network Interface` is a virtual network card that can be attached to an instance in a VPC which allows the instance to communicate with other instances and services in the VPC, as well as with the internet.
