## Solution
1. Log in to the AWS Management Console using the provided credentials.
2. Navigate to the EC2 Dashboard in the `us-east-1` region.
3. In the left-hand menu, click on "Instances" to view the list of EC2 instances.
4. Locate the instance named `nautilus-ec2` in the list of instances.
5. Select the `nautilus-ec2` instance by clicking the checkbox next to it.
6. In the "Instance State" section of the instance details, click on the "Actions" dropdown menu.
7. From the dropdown menu, select "Instance Settings" and then click on "Change Termination Protection."
8. In the "Change Termination Protection" dialog box, check the box to enable termination protection.
9. Click the "Save" button to apply the changes.

## Notes
- `Termination protection` is a feature that prevents accidental termination of an EC2 instance.
