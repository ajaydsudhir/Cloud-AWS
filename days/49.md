# Day 49: Centralized Audit Logging with VPC Peering

## Task
The Nautilus DevOps team needs to build a secure and scalable log aggregation setup within their AWS environment. The goal is to gather log files from an internal EC2 instance running in a private VPC, transfer them securely to another EC2 instance in a public VPC, and then push those logs to a secure S3 bucket.

1. A VPC named `nautilus-priv-vpc` already exists with a private subnet named `nautilus-priv-subnet`, a route table named `nautilus-priv-rt`, and an EC2 instance named `nautilus-priv-ec2` (using `ubuntu` image). This instance uses the SSH key pair `nautilus-key.pem` already available on the AWS client host at `/root/.ssh/`.

2. Your task is to:
    - Create a new VPC named `nautilus-pub-vpc`.
    - Create a subnet named `nautilus-pub-subnet` and a route table named `nautilus-pub-rt` under this public VPC.
    - Attach an internet gateway to `nautilus-pub-vpc` and configure the public route table to enable internet access.
    - Launch an EC2 instance named `nautilus-pub-ec2` into the public subnet using the same key pair as the private instance.
    - Create an IAM role named `nautilus-s3-role` with `PutObject` permission to an S3 bucket and attach it to the public EC2 instance.
    - Create a new private S3 bucket named `nautilus-s3-logs-390744526`.
    - Configure a VPC Peering named `nautilus-vpc-peering` between the private and public VPCs.
    - Modify both `nautilus-priv-rt` and `nautilus-pub-rt` to route each other's CIDR blocks through the peering connection.
    - On the private instance, configure a cron job to push the `/var/log/boots.log` file to the public instance (using `scp` or `rsync`).
    - On the public instance, configure a cron job to push that same file to the created S3 bucket.
    - The uploaded file must be stored in the S3 bucket under the path `nautilus-priv-vpc/boot/boots.log`.

**Notes:** Create the resources only in `us-east-1` region.

## Solution
1. Set Variables:
    ```bash
    REGION="us-east-1"
    PRIV_VPC="nautilus-priv-vpc"
    PRIV_RT="nautilus-priv-rt"
    PUB_VPC="nautilus-pub-vpc"
    PUB_SUBNET="nautilus-pub-subnet"
    PUB_RT="nautilus-pub-rt"
    VPC_PEERING="nautilus-vpc-peering"
    PUB_EC2="nautilus-pub-ec2"
    PRIV_S3="nautilus-s3-logs-390744526"
    S3_ROLE="nautilus-s3-role"
    KEY_NAME="nautilus-key"
    ```
2. Create Public VPC and Networking:
    ```bash
    PUB_VPC_ID=$(aws ec2 create-vpc --cidr-block 10.20.0.0/16 --region $REGION --query 'Vpc.VpcId' --output text)

    aws ec2 create-tags --resources $PUB_VPC_ID --tags Key=Name,Value=$PUB_VPC

    PUB_SUBNET_ID=$(aws ec2 create-subnet --vpc-id $PUB_VPC_ID --cidr-block 10.20.1.0/24 --region $REGION --query 'Subnet.SubnetId' --output text)

    aws ec2 create-tags --resources $PUB_SUBNET_ID --tags Key=Name,Value=$PUB_SUBNET

    aws ec2 modify-subnet-attribute --subnet-id $PUB_SUBNET_ID --map-public-ip-on-launch

    IGW_ID=$(aws ec2 create-internet-gateway --region $REGION --query 'InternetGateway.InternetGatewayId' --output text)

    aws ec2 attach-internet-gateway --internet-gateway-id $IGW_ID --vpc-id $PUB_VPC_ID

    PUB_RT_ID=$(aws ec2 create-route-table --vpc-id $PUB_VPC_ID --region $REGION --query 'RouteTable.RouteTableId' --output text)

    aws ec2 create-tags --resources $PUB_RT_ID --tags Key=Name,Value=$PUB_RT

    aws ec2 create-route --route-table-id $PUB_RT_ID --destination-cidr-block 0.0.0.0/0 --gateway-id $IGW_ID

    aws ec2 associate-route-table --subnet-id $PUB_SUBNET_ID --route-table-id $PUB_RT_ID
    ```
3. Launch Public EC2 Instance:
    ```bash
    AMI_ID=$(aws ec2 describe-images --region $REGION --owners 099720109477 --filters "Name=name,Values=ubuntu/images/hvm-ssd/ubuntu-focal-20.04-amd64-server-*" "Name=state,Values=available" --query 'Images | sort_by(@,&CreationDate)[-1].ImageId' --output text)

    PUB_EC2_ID=$(aws ec2 run-instances --region $REGION --image-id $AMI_ID --instance-type t2.micro --key-name $KEY_NAME --subnet-id $PUB_SUBNET_ID --associate-public-ip-address --query 'Instances[0].InstanceId' --output text)

    aws ec2 create-tags --resources $PUB_EC2_ID --tags Key=Name,Value=$PUB_EC2

    PUB_PRIVATE_IP=$(aws ec2 describe-instances --instance-ids $PUB_EC2_ID --region $REGION --query 'Reservations[0].Instances[0].PrivateIpAddress' --output text)

    PUB_PUBLIC_IP=$(aws ec2 describe-instances --instance-ids $PUB_EC2_ID --region $REGION --query 'Reservations[0].Instances[0].PublicIpAddress' --output text)

    echo "Public IP: $PUB_PUBLIC_IP"
    echo "Private IP: $PUB_PRIVATE_IP"
    ```
4. Create Private S3 Bucket:
    ```bash
    aws s3api create-bucket --bucket $PRIV_S3 --region $REGION

    aws s3api put-public-access-block --bucket $PRIV_S3 --region $REGION --public-access-block-configuration BlockPublicAcls=true,IgnorePublicAcls=true,BlockPublicPolicy=true,RestrictPublicBuckets=true
    ```
5. Create IAM Role and Attach It to EC2:
    ```bash
    cat > trust.json <<'EOF'
    {
    "Version": "2012-10-17",
    "Statement": [{
        "Effect": "Allow",
        "Principal": {"Service": "ec2.amazonaws.com"},
        "Action": "sts:AssumeRole"
    }]
    }
    EOF

    aws iam create-role --role-name $S3_ROLE --assume-role-policy-document file://trust.json
    ```
6. Create and attach the S3 permission policy:
    ```bash
    ACCOUNT_ID=$(aws sts get-caller-identity --query Account --output text)

    cat > s3-policy.json <<EOF
    {
    "Version": "2012-10-17",
    "Statement": [{
        "Effect": "Allow",
        "Action": "s3:PutObject",
        "Resource": "arn:aws:s3:::$PRIV_S3/*"
    }]
    }
    EOF

    aws iam create-policy --policy-name s3-put-policy --policy-document file://s3-policy.json

    aws iam attach-role-policy --role-name $S3_ROLE --policy-arn arn:aws:iam::$ACCOUNT_ID:policy/s3-put-policy

    aws iam create-instance-profile --instance-profile-name $S3_ROLE

    aws iam add-role-to-instance-profile --instance-profile-name $S3_ROLE --role-name $S3_ROLE

    sleep 10

    aws ec2 associate-iam-instance-profile --instance-id $PUB_EC2_ID --iam-instance-profile Name=$S3_ROLE --region $REGION
    ```
7. Configure VPC Peering:
    ```bash
    PRIV_VPC_ID=$(aws ec2 describe-vpcs --region $REGION --filters "Name=tag:Name,Values=$PRIV_VPC" --query 'Vpcs[0].VpcId' --output text)

    PEER_ID=$(aws ec2 create-vpc-peering-connection --region $REGION --vpc-id $PRIV_VPC_ID --peer-vpc-id $PUB_VPC_ID --query 'VpcPeeringConnection.VpcPeeringConnectionId' --output text)

    aws ec2 accept-vpc-peering-connection --region $REGION --vpc-peering-connection-id $PEER_ID

    aws ec2 create-tags --resources $PEER_ID --tags Key=Name,Value=$VPC_PEERING
    ```
8. Update Both Route Tables:
    ```bash
    PRIV_CIDR=$(aws ec2 describe-vpcs --vpc-ids $PRIV_VPC_ID --region $REGION --query 'Vpcs[0].CidrBlock' --output text)

    PUB_CIDR=$(aws ec2 describe-vpcs --vpc-ids $PUB_VPC_ID --region $REGION --query 'Vpcs[0].CidrBlock' --output text)

    PRIV_RT_ID=$(aws ec2 describe-route-tables --region $REGION --filters "Name=tag:Name,Values=$PRIV_RT" --query 'RouteTables[0].RouteTableId' --output text)

    aws ec2 create-route --route-table-id $PRIV_RT_ID --destination-cidr-block $PUB_CIDR --vpc-peering-connection-id $PEER_ID --region $REGION

    aws ec2 create-route --route-table-id $PUB_RT_ID --destination-cidr-block $PRIV_CIDR --vpc-peering-connection-id $PEER_ID --region $REGION
    ```
9. Configure SSH and Cron on the Private Instance:
    ```bash
    chmod 400 /root/.ssh/nautilus-key.pem

    ssh -i /root/.ssh/nautilus-key.pem ubuntu@<PRIVATE_INSTANCE_IP>

    mkdir -p ~/.ssh
    chmod 700 ~/.ssh

    chmod 400 ~/.ssh/nautilus-key.pem

    crontab -e
    ```
10. Add the following cron entry, replacing `<PUB_PRIVATE_IP>` with the public instance's private IP:
    ```bash
    * * * * * /usr/bin/scp -i /home/ubuntu/.ssh/nautilus-key.pem -o StrictHostKeyChecking=no /var/log/boots.log ubuntu@<PUB_PRIVATE_IP>:/home/ubuntu/boots.log
    ```
11. Configure Cron on the Public Instance:
    ```bash
    ssh -i /root/.ssh/nautilus-key.pem ubuntu@$PUB_PUBLIC_IP

    sudo apt-get update
    sudo apt-get install -y awscli

    aws sts get-caller-identity

    crontab -e
    ```
12. Add the following cron entry to upload the log file to S3:
    ```bash
    * * * * * /usr/bin/aws s3 cp /home/ubuntu/boots.log s3://nautilus-s3-logs-390744526/nautilus-priv-vpc/boot/boots.log --region us-east-1 >> /home/ubuntu/s3-upload.log 2>&1
    ```
13. Verify the Upload:
    ```bash
    aws s3 ls s3://nautilus-s3-logs-390744526/nautilus-priv-vpc/boot/boots.log --region us-east-1

    cat /home/ubuntu/s3-upload.log
    ```
