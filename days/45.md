# Day 45: Configure NAT Gateway for Internet Access in a Private VPC

## Task
The Nautilus DevOps team is tasked with enabling internet access for an EC2 instance running in a private subnet. This instance should be able to upload a test file to a public S3 bucket once it can access the internet. To achieve this, the team must set up a NAT Gateway in a public subnet within the same VPC.

1. A VPC named `datacenter-priv-vpc` and a private subnet `datacenter-priv-subnet` have already been created.

2. An EC2 instance named `datacenter-priv-ec2` is already running in the private subnet.

3. The EC2 instance is configured with a cron job that uploads a test file to a bucket `datacenter-nat-99726503` once internet is accessible.

Your task is to:
- Create a public subnet named `datacenter-pub-subnet` in the same VPC.
- Create an Internet Gateway and attach it to the VPC.
- Create a route table `datacenter-pub-rt` and associate it with the public subnet.
- Allocate an Elastic IP and create a NAT Gateway named `datacenter-natgw`.
- Create a new, dedicated private route table named `datacenter-priv-rt` (do not reuse or edit the VPC's Main route table), explicitly associate it with the private subnet `datacenter-priv-subnet`, and add a route for `0.0.0.0/0` via the NAT Gateway.

Once complete, verify that the EC2 instance can reach the internet by confirming the presence of the test file in the S3 bucket `datacenter-nat-99726503`. After completing all the configuration, please wait a few minutes for the test file to appear in the bucket, as it may take `2–3 minutes`.

**Notes:** Create the resources only in `us-east-1` region.

## Solution
1. Login to the AWS Management Console using the provided credentials.
2. Navigate to the VPC service and create a new public subnet named `datacenter-pub-subnet` in the `datacenter-priv-vpc` VPC with a CIDR block of `10.1.0.0/24`.
3. Create an Internet Gateway named `datacenter-igw` and attach it to the `datacenter-priv-vpc` VPC.
4. Create a new route table named `datacenter-pub-rt` and associate it with the `datacenter-pub-subnet` while also adding a route for `0.0.0.0/0` to the Internet Gateway.
5. Create a NAT Gateway named `datacenter-natgw` in the `datacenter-pub-subnet` and allocate an Elastic IP for it.
6. Add a route for `0.0.0.0/0` in the route table connected to the private subnet that points to the NAT Gateway; ensure that the route table is associated with the private subnet.
7. Check for the presence of the test file in the S3 bucket `datacenter-nat-99726503`.

1. Configure AWS CLI variables by setting the region and resource names as follows:
    ```bash
    export AWS_DEFAULT_REGION="us-east-1"
    export AWS_REGION="us-east-1"
    export AWS_PAGER=""

    VPC_NAME="datacenter-priv-vpc"
    PUB_SUBNET_NAME="datacenter-pub-subnet"
    PUB_RT_NAME="datacenter-pub-rt"
    IGW_NAME="datacenter-igw"
    NAT_GW_NAME="datacenter-natgw"
    PRIVATE_SUBNET_NAME="datacenter-priv-subnet"
    PRIVATE_RT_NAME="datacenter-priv-rt"
    EC2_NAME="datacenter-priv-ec2"
    TEST_BUCKET="datacenter-nat-99726503"

    aws sts get-caller-identity
    ```
2. Identify the existing VPC and private subnet:
    ```bash
    VPC_ID=$(aws ec2 describe-vpcs \
    --filters "Name=tag:Name,Values=$VPC_NAME" \
    --query "Vpcs[0].VpcId" \
    --output text)

    PRIV_SUBNET_ID=$(aws ec2 describe-subnets \
    --filters "Name=tag:Name,Values=$PRIVATE_SUBNET_NAME" \
                "Name=vpc-id,Values=$VPC_ID" \
    --query "Subnets[0].SubnetId" \
    --output text)

    echo "VPC_ID=$VPC_ID"
    echo "PRIV_SUBNET_ID=$PRIV_SUBNET_ID"

    aws ec2 describe-vpcs \
    --vpc-ids "$VPC_ID" \
    --query "Vpcs[0].{VpcId:VpcId,CidrBlock:CidrBlock,State:State}" \
    --output table

    aws ec2 describe-subnets \
    --filters "Name=vpc-id,Values=$VPC_ID" \
    --query "Subnets[].{Name:Tags[?Key=='Name']|[0].Value,SubnetId:SubnetId,CidrBlock:CidrBlock,AZ:AvailabilityZone,State:State}" \
    --output table
    ```
3. Create the public subnet:
    ```bash
    PUB_SUBNET_ID=$(aws ec2 create-subnet \
    --vpc-id "$VPC_ID" \
    --cidr-block 10.1.2.0/24 \
    --availability-zone us-east-1a \
    --tag-specifications "ResourceType=subnet,Tags=[{Key=Name,Value=$PUB_SUBNET_NAME}]" \
    --query "Subnet.SubnetId" \
    --output text)

    echo "PUB_SUBNET_ID=$PUB_SUBNET_ID"

    aws ec2 modify-subnet-attribute \
    --subnet-id "$PUB_SUBNET_ID" \
    --map-public-ip-on-launch

    aws ec2 describe-subnets \
    --subnet-ids "$PUB_SUBNET_ID" \
    --query "Subnets[0].{SubnetId:SubnetId,CidrBlock:CidrBlock,AZ:AvailabilityZone,State:State}" \
    --output table
    ```
4. Create and attach the Internet Gateway:
    ```bash
    IGW_ID=$(aws ec2 create-internet-gateway \
    --query "InternetGateway.InternetGatewayId" \
    --output text)

    echo "IGW_ID=$IGW_ID"

    aws ec2 create-tags \
    --resources "$IGW_ID" \
    --tags "Key=Name,Value=$IGW_NAME"

    aws ec2 attach-internet-gateway \
    --internet-gateway-id "$IGW_ID" \
    --vpc-id "$VPC_ID"

    aws ec2 describe-internet-gateways \
    --internet-gateway-ids "$IGW_ID" \
    --query "InternetGateways[0].{InternetGatewayId:InternetGatewayId,Attachments:Attachments}" \
    --output table
    ```
5. Create and configure the public route table:
    ```bash
    PUB_RT_ID=$(aws ec2 create-route-table \
    --vpc-id "$VPC_ID" \
    --query "RouteTable.RouteTableId" \
    --output text)

    echo "PUB_RT_ID=$PUB_RT_ID"

    aws ec2 create-tags \
    --resources "$PUB_RT_ID" \
    --tags "Key=Name,Value=$PUB_RT_NAME"

    aws ec2 create-route \
    --route-table-id "$PUB_RT_ID" \
    --destination-cidr-block 0.0.0.0/0 \
    --gateway-id "$IGW_ID"

    aws ec2 associate-route-table \
    --route-table-id "$PUB_RT_ID" \
    --subnet-id "$PUB_SUBNET_ID"

    aws ec2 describe-route-tables \
    --route-table-ids "$PUB_RT_ID" \
    --query "RouteTables[0].{RouteTableId:RouteTableId,Routes:Routes,Associations:Associations}" \
    --output json
    ```
6. Allocate an Elastic IP:
    ```bash
    EIP_ALLOC_ID=$(aws ec2 allocate-address \
    --domain vpc \
    --query "AllocationId" \
    --output text)

    echo "EIP_ALLOC_ID=$EIP_ALLOC_ID"

    aws ec2 describe-addresses \
    --allocation-ids "$EIP_ALLOC_ID" \
    --query "Addresses[0].{AllocationId:AllocationId,PublicIp:PublicIp,Domain:Domain}" \
    --output table
    ```
7. Create the NAT Gateway:
    ```bash
    NAT_GW_ID=$(aws ec2 create-nat-gateway \
    --subnet-id "$PUB_SUBNET_ID" \
    --allocation-id "$EIP_ALLOC_ID" \
    --tag-specifications "ResourceType=natgateway,Tags=[{Key=Name,Value=$NAT_GW_NAME}]" \
    --query "NatGateway.NatGatewayId" \
    --output text)

    echo "NAT_GW_ID=$NAT_GW_ID"
    ```
8. Wait for the NAT Gateway to become available and run:
    ```bash
    aws ec2 wait nat-gateway-available \
    --nat-gateway-ids "$NAT_GW_ID"

    aws ec2 describe-nat-gateways \
    --nat-gateway-ids "$NAT_GW_ID" \
    --query "NatGateways[0].{NatGatewayId:NatGatewayId,Name:Tags[?Key=='Name']|[0].Value,State:State,SubnetId:SubnetId,VpcId:VpcId}" \
    --output table
    ```
9. Create a dedicated private route table named `datacenter-priv-rt`:
    ```bash
    PRIV_RT_ID=$(aws ec2 create-route-table \
    --vpc-id "$VPC_ID" \
    --query "RouteTable.RouteTableId" \
    --output text)

    echo "PRIV_RT_ID=$PRIV_RT_ID"

    aws ec2 create-tags \
    --resources "$PRIV_RT_ID" \
    --tags "Key=Name,Value=$PRIVATE_RT_NAME"

    aws ec2 associate-route-table \
    --route-table-id "$PRIV_RT_ID" \
    --subnet-id "$PRIV_SUBNET_ID"

    aws ec2 create-route \
    --route-table-id "$PRIV_RT_ID" \
    --destination-cidr-block 0.0.0.0/0 \
    --nat-gateway-id "$NAT_GW_ID"
    ```
10. Verify the private route table:
    ```bash
    aws ec2 describe-route-tables \
    --route-table-ids "$PRIV_RT_ID" \
    --query "RouteTables[0].{RouteTableId:RouteTableId,VpcId:VpcId,Routes:Routes,Associations:Associations}" \
    --output json
    ```
11. Verify the test file in S3
    ```bash
    aws s3 ls "s3://$TEST_BUCKET"
    aws s3api list-objects-v2 \
    --bucket "$TEST_BUCKET" \
    --query "Contents[?Key=='datacenter-test.txt'].{Key:Key,Size:Size,LastModified:LastModified}" \
    --output table
    ```
12. Run a final validation script:
    ```bash
    #!/usr/bin/env bash

    set -u
    export AWS_DEFAULT_REGION=us-east-1
    export AWS_PAGER=""

    PASS=0
    FAIL=0

    check() {
    if [ "$2" = "true" ]; then
        printf 'PASS: %s\n' "$1"
        PASS=$((PASS + 1))
    else
        printf 'FAIL: %s\n' "$1"
        FAIL=$((FAIL + 1))
    fi
    }

    VPC_ID=$(aws ec2 describe-vpcs \
    --filters "Name=tag:Name,Values=$VPC_NAME" \
    --query 'Vpcs[0].VpcId' --output text)

    PUB_SUBNET_ID=$(aws ec2 describe-subnets \
    --filters "Name=tag:Name,Values=$PUB_SUBNET_NAME" \
                "Name=vpc-id,Values=$VPC_ID" \
    --query 'Subnets[0].SubnetId' --output text)

    PRIV_SUBNET_ID=$(aws ec2 describe-subnets \
    --filters "Name=tag:Name,Values=$PRIVATE_SUBNET_NAME" \
                "Name=vpc-id,Values=$VPC_ID" \
    --query 'Subnets[0].SubnetId' --output text)

    PUB_RT_ID=$(aws ec2 describe-route-tables \
    --filters "Name=tag:Name,Values=$PUB_RT_NAME" \
                "Name=vpc-id,Values=$VPC_ID" \
    --query 'RouteTables[0].RouteTableId' --output text)

    PRIV_RT_ID=$(aws ec2 describe-route-tables \
    --filters "Name=tag:Name,Values=$PRIVATE_RT_NAME" \
                "Name=vpc-id,Values=$VPC_ID" \
    --query 'RouteTables[0].RouteTableId' --output text)

    NAT_GW_ID=$(aws ec2 describe-nat-gateways \
    --filter "Name=vpc-id,Values=$VPC_ID" \
            "Name=tag:Name,Values=$NAT_GW_NAME" \
    --query 'NatGateways[0].NatGatewayId' --output text)

    IGW_ID=$(aws ec2 describe-internet-gateways \
    --filters "Name=attachment.vpc-id,Values=$VPC_ID" \
    --query "InternetGateways[?Attachments[?VpcId=='$VPC_ID']].InternetGatewayId | [0]" \
    --output text)

    echo "=== Resource IDs ==="
    printf 'VPC: %s\nPublic subnet: %s\nPrivate subnet: %s\n' \
    "$VPC_ID" "$PUB_SUBNET_ID" "$PRIV_SUBNET_ID"
    printf 'Public RT: %s\nPrivate RT: %s\nIGW: %s\nNAT: %s\n' \
    "$PUB_RT_ID" "$PRIV_RT_ID" "$IGW_ID" "$NAT_GW_ID"

    check "VPC exists" "$([ "$VPC_ID" != None ] && [ -n "$VPC_ID" ] && echo true || echo false)"
    check "Public subnet exists in target VPC" "$([ "$PUB_SUBNET_ID" != None ] && [ -n "$PUB_SUBNET_ID" ] && echo true || echo false)"
    check "Private subnet exists in target VPC" "$([ "$PRIV_SUBNET_ID" != None ] && [ -n "$PRIV_SUBNET_ID" ] && echo true || echo false)"

    IGW_ATTACHED=$(aws ec2 describe-internet-gateways \
    --internet-gateway-ids "$IGW_ID" \
    --query "length(InternetGateways[?Attachments[?VpcId=='$VPC_ID' && State=='available']])" \
    --output text 2>/dev/null)
    check "Internet Gateway attached to VPC" "$([ "$IGW_ATTACHED" = 1 ] && echo true || echo false)"

    PUB_RT_VPC=$(aws ec2 describe-route-tables --route-table-ids "$PUB_RT_ID" \
    --query 'RouteTables[0].VpcId' --output text 2>/dev/null)
    check "Public route table belongs to VPC" "$([ "$PUB_RT_VPC" = "$VPC_ID" ] && echo true || echo false)"

    PUB_ASSOC=$(aws ec2 describe-route-tables --route-table-ids "$PUB_RT_ID" \
    --query "length(RouteTables[0].Associations[?SubnetId=='$PUB_SUBNET_ID' && Main==\`false\`])" \
    --output text 2>/dev/null)
    check "Public route table explicitly associated with public subnet" "$([ "$PUB_ASSOC" = 1 ] && echo true || echo false)"

    PUB_ROUTE=$(aws ec2 describe-route-tables --route-table-ids "$PUB_RT_ID" \
    --query "length(RouteTables[0].Routes[?DestinationCidrBlock=='0.0.0.0/0' && GatewayId=='$IGW_ID' && State=='active'])" \
    --output text 2>/dev/null)
    check "Public default route points to active IGW" "$([ "$PUB_ROUTE" = 1 ] && echo true || echo false)"

    NAT_STATE=$(aws ec2 describe-nat-gateways --nat-gateway-ids "$NAT_GW_ID" \
    --query 'NatGateways[0].State' --output text 2>/dev/null)
    check "NAT Gateway is available" "$([ "$NAT_STATE" = available ] && echo true || echo false)"

    NAT_SUBNET=$(aws ec2 describe-nat-gateways --nat-gateway-ids "$NAT_GW_ID" \
    --query 'NatGateways[0].SubnetId' --output text 2>/dev/null)
    check "NAT Gateway is in public subnet" "$([ "$NAT_SUBNET" = "$PUB_SUBNET_ID" ] && echo true || echo false)"

    NAT_EIP=$(aws ec2 describe-nat-gateways --nat-gateway-ids "$NAT_GW_ID" \
    --query 'NatGateways[0].NatGatewayAddresses[?AllocationId!=null].AllocationId | [0]' \
    --output text 2>/dev/null)
    check "NAT Gateway has an Elastic IP allocation" "$([ "$NAT_EIP" != None ] && [ -n "$NAT_EIP" ] && echo true || echo false)"

    PRIV_RT_VPC=$(aws ec2 describe-route-tables --route-table-ids "$PRIV_RT_ID" \
    --query 'RouteTables[0].VpcId' --output text 2>/dev/null)
    check "Private route table belongs to VPC" "$([ "$PRIV_RT_VPC" = "$VPC_ID" ] && echo true || echo false)"

    PRIV_IS_MAIN=$(aws ec2 describe-route-tables --route-table-ids "$PRIV_RT_ID" \
    --query 'RouteTables[0].Associations[?Main==`true`] | length(@)' \
    --output text 2>/dev/null)
    check "Private route table is not the main route table" "$([ "$PRIV_IS_MAIN" = 0 ] && echo true || echo false)"

    PRIV_ASSOC=$(aws ec2 describe-route-tables --route-table-ids "$PRIV_RT_ID" \
    --query "length(RouteTables[0].Associations[?SubnetId=='$PRIV_SUBNET_ID' && Main==\`false\`])" \
    --output text 2>/dev/null)
    check "Private route table explicitly associated with private subnet" "$([ "$PRIV_ASSOC" = 1 ] && echo true || echo false)"

    PRIV_ROUTE=$(aws ec2 describe-route-tables --route-table-ids "$PRIV_RT_ID" \
    --query "length(RouteTables[0].Routes[?DestinationCidrBlock=='0.0.0.0/0' && NatGatewayId=='$NAT_GW_ID' && State=='active'])" \
    --output text 2>/dev/null)
    check "Private default route points to active NAT Gateway" "$([ "$PRIV_ROUTE" = 1 ] && echo true || echo false)"

    S3_FILE=$(aws s3api list-objects-v2 \
    --bucket "$TEST_BUCKET" \
    --query "length(Contents[?Key=='datacenter-test.txt'])" \
    --output text 2>/dev/null)
    check "Test file exists in S3 bucket" "$([ "$S3_FILE" = 1 ] && echo true || echo false)"

    echo
    echo "=== Final result: $PASS passed, $FAIL failed ==="

    if [ "$FAIL" -eq 0 ]; then
    echo "ALL CHECKS PASSED"
    else
    echo "INVESTIGATE FAILED CHECKS ABOVE"
    fi
    ```
