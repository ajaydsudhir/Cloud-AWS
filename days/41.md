## Solution
1. Login to the AWS console using the provided credentials and navigate to the KMS service in the `us-east-1` region.
2. Navigate to Key Management Service (KMS) and create a new key with the following configuration:
   - Key Type: Symmetric
   - Key Usage: Encrypt and Decrypt
   - Alias: `xfusion-KMS-Key`
   - Key Administrator: kk_labs_user_427424
   - Key Usage Permissions: kk_labs_user_427424
3. Run the following command to encrypt `SensitiveData.txt` and save the encrypted data as `EncryptedData.bin`:
   ```bash
   aws kms encrypt \
      --key-id <Key_ID> \
      --plaintext fileb://SensitiveData.txt \
      --output text \
      --query CiphertextBlob | base64 \
      --decode > /root/EncryptedData.bin
   ```
4. Run the following command to decrypt `EncryptedData.bin` and save the decrypted data as `DecryptedData.txt`:
   ```bash
   aws kms decrypt \
      --ciphertext-blob fileb://EncryptedData.bin \
      --key-id <Key_ID> \
      --output text \
      --query Plaintext | base64 \
      --decode > DecryptedData.txt
   ```
