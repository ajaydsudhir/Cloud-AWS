## Solution
1. Login to the AWS Management Console using the provided credentials and navigate to the AWS Lambda service in the `us-east-1` region.
2. Click on the "Create function" button to start creating a new Lambda function.
3. Choose "Author from scratch" and enter the following details:
   - Function name: `nautilus-lambda`
   - Runtime: `Python 3.x` (choose the latest available version)
4. Under "Permissions", choose "Use an existing role" and select the IAM role named `lambda_execution_role`. If the role does not exist, create it with the necessary permissions for Lambda execution.
5. Click "Create function" to create the Lambda function.
6. In the function code editor, replace the default code with the following Python code:
```python
def lambda_handler(event, context): 
    return {
        'statusCode': 200,
        'body': 'Welcome to KKE AWS Labs!'
    }
```
7. Click "Deploy" to save the changes to the Lambda function and "Test" the function to ensure it returns the expected output with a status code of `200` and the body `Welcome to KKE AWS Labs!`.
