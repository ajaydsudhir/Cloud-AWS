## Solution
1. Log in to the AWS Management Console using the provided credentials.
2. Create a new EC2 instance of type `t2.micro` and name it `devops-ec2`.
3. On the `aws-client` host, check if the SSH key `id_rsa` exists in the `/root/.ssh/` directory. If it does not exist, generate a new SSH key pair using the command:
```bash
ssh-keygen
```
4. Connect to the EC2 instance in the console and navigate to the `/root/.ssh/` directory.
5. Add the public key from the `id_rsa.pub` file on the `aws-client` host to the `authorized_keys` file on the EC2 instance. You can do this by copying the contents of `id_rsa.pub` and pasting it to `/root/.ssh/authorized_keys` using `vi` on the EC2 instance.
6. SSH into the EC2 instance from the `aws-client` host using the command:
```bash
ssh root@<EC2_INSTANCE_PUBLIC_IP>
```

## Notes
- Secure SSH access is a best practice for managing EC2 instances, as it allows for encrypted communication and reduces the risk of unauthorized access.
