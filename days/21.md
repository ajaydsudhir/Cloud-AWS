## Solution
1. Log in to the AWS Management Console using the provided credentials.
2. Navigate to the EC2 service in the `us-east-1` region.
3. Click on "Launch Instance" to create a new EC2 instance.
4. Choose an Amazon Machine Image (AMI) such as Ubuntu.
5. Select the instance type as `t2.micro`.
6. Configure the instance details as needed, for the network security group, you can create a new one or use an existing one that allows SSH and HTTP access.
7. Add storage if necessary, or keep the default settings.
8. Add tags to the instance, naming it `xfusion-ec2`.
9. Configure the security group to allow necessary inbound traffic (e.g., SSH, HTTP).
10. Review and launch the instance, creating a new key pair or using an existing one for SSH access.
11. After the instance is launched, navigate to the "Elastic IPs" section under the "Network & Security" category in the EC2 dashboard.
12. Allocate a new Elastic IP address and associate it with the newly created EC2 instance `xfusion-ec2`.
13. Name the Elastic IP as `xfusion-eip` for easy identification.
14. Verify that the Elastic IP is associated with the EC2 instance and that the instance is running properly.
