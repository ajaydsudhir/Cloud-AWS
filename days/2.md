## Solution
1. Log in to the AWS Management Console using the provided credentials and navigate to the EC2 service in the `us-east-1` region.
2. In the left-hand navigation pane, click on "Security Groups" under the "Network & Security" section.
3. Click the "Create security group" button.
4. In the "Create Security Group" form, enter the following details:
   - Security group name: `datacenter-sg`
   - Description: `Security group for Nautilus App Servers`
   - VPC: Select the default VPC (usually named "default").
5. Under the "Inbound rules" section, click "Add rule" and configure the first rule as follows:
   - Type: `HTTP`
   - Protocol: `TCP`
   - Port Range: `80`
   - Source: `0.0.0.0/0`
6. Click "Add rule" again to configure the second rule:
   - Type: `SSH`
   - Protocol: `TCP`
   - Port Range: `22`
   - Source: `0.0.0.0/0`
7. Review the security group settings and click the "Create security group" button to finalize the creation of the security group.

## Notes
- A `security group` acts as a virtual firewall for your EC2 instances to control inbound and outbound traffic which is essential to ensure the security and accessibility of your applications hosted on AWS.
- Security groups are stateful, meaning that if you allow inbound traffic, the corresponding outbound traffic is automatically allowed.
