# Day 25: Setting Up an EC2 Instance and CloudWatch Alarm

## Task
The Nautilus DevOps team has been tasked with setting up an EC2 instance for their application. To ensure the application performs optimally, they also need to create a CloudWatch alarm to monitor the instance's CPU utilization. The alarm should trigger if the CPU utilization exceeds 90% for one consecutive 5-minute period. To send notifications, use the SNS topic named `nautilus-sns-topic` which is already created.

1. **Launch EC2 Instance:** Create an EC2 instance named `nautilus-ec2` using any appropriate Ubuntu AMI.

2. **Create CloudWatch Alarm:** Create a CloudWatch alarm named `nautilus-alarm` with the following specifications:
- **Statistic:** Average
- **Metric:** CPU Utilization
- **Threshold:** >= 90% for 1 consecutive 5-minute period.
- **Alarm Actions:** Send a notification to `nautilus-sns-topic`.

## Solution
1. Login to the AWS Management Console using the provided credentials and navigate to the EC2 service in the `us-east-1` region.
2. Launch a new EC2 instance:
   - Choose an appropriate Ubuntu AMI.
   - Name the instance `nautilus-ec2`.
   - Configure instance details, add storage, and configure security groups as needed.
   - Launch the instance.
3. After the instance is running, navigate to the CloudWatch service in the AWS Management Console.
4. Create a new CloudWatch alarm:
   - Click on "Alarms" in the left-hand menu and then click "Create Alarm".
   - Select the `nautilus-ec2` instance and choose the "CPU Utilization" metric.
   - Set the statistic to "Average" and the threshold to ">= 90%" for 1 consecutive 5-minute period.
   - Under "Actions", select "Send a notification to" and choose the existing SNS topic `nautilus-sns-topic`.
   - Name the alarm `nautilus-alarm` and review the settings.
   - Click "Create Alarm" to finalize the setup.
