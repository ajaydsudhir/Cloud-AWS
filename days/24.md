# Day 24: Setting Up an Application Load Balancer for an EC2 Instance

## Task
The Nautilus DevOps team is currently working on setting up a simple application on the AWS cloud. They aim to establish an Application Load Balancer (ALB) in front of an EC2 instance where an Nginx server is currently running. While the Nginx server currently serves a sample page, the team plans to deploy the actual application later.

1. Set up an Application Load Balancer named `datacenter-alb`.
2. Create a target group named `datacenter-tg`.
3. Create a security group named `datacenter-sg` to open port `80` for the public.
4. Attach this security group to the ALB.
5. The ALB should route traffic on port `80` to port `80` of the `datacenter-ec2` instance.
6. Make appropriate changes in the default security group attached to the EC2 instance if necessary.

## Solution
1. Log in to the AWS Management Console using the provided credentials.
2. Navigate to the EC2 service and click on the "Load Balancers" option in the left-hand menu.
3. Click on the "Create Load Balancer" button and select "Application Load Balancer".
4. Enter the name `datacenter-alb`, select the scheme as "Internet-facing", and choose the appropriate VPC and availability zones.
5. Click "Next: Configure Security Settings"
6. Since we are not using HTTPS, click "Next: Configure Security Groups".
7. Click on "Create a new security group" and name it `datacenter-sg`. Add a rule to allow inbound traffic on port `80` from `0.0.0.0/0`.
8. Click "Next: Configure Routing". Create a new target group named `datacenter-tg`, select the target type as "Instance", and set the protocol and port to `HTTP` and `80`, respectively.
9. Click "Next: Register Targets". Select the `datacenter-ec2` instance and click "Add to registered". Click "Next: Review" and then "Create".
10. After the ALB is created, navigate to the "Target Groups" section in the EC2 service and select the `datacenter-tg` target group. Ensure that the `datacenter-ec2` instance is listed as healthy.
11. If necessary, modify the default security group attached to the `datacenter-ec2` instance to allow inbound traffic on port `80` from the `datacenter-sg` security group.
12. Test the setup by accessing the DNS name of the `datacenter-alb` in a web browser. You should see the sample page served by the Nginx server on the `datacenter-ec2` instance.
