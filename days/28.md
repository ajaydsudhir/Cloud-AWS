# Day 28: Creating a Private ECR Repository

## Task
The Nautilus DevOps team has been tasked with setting up a containerized application. They need to create a private Amazon Elastic Container Registry (ECR) repository to store their Docker images. Once the repository is created, they will build a Docker image from a Dockerfile located on the `aws-client` host and push this image to the ECR repository. This process is essential for maintaining and deploying containerized applications in a streamlined manner.

Create a private ECR repository named `xfusion-ecr`. There is a Dockerfile under `/root/pyapp` directory on `aws-client` host, build a docker image using this Dockerfile and push the same to the newly created ECR repo, the image tag must be `latest`.

## Solution
1. Log in to the AWS Management Console using the provided credentials.
2. Navigate to the Amazon ECR service in the `us-east-1` region.
3. Click on "Create repository" which creates a new private ECR repository and enter the following details:
   - Repository name: `devops-ecr`
   - Image tag mutability: `Mutable`
   - Encryption settings: `AES-256`
4. Click on "Create repository" to create the ECR repository and then view the `Push commands` to get the commands for pushing the Docker image to the ECR repository.
5. Run the following commands:
```bash
aws ecr get-login-password --region us-east-1 | docker login --username AWS --password-stdin 243552893788.dkr.ecr.us-east-1.amazonaws.com
docker build -t xfusion-ecr .
docker tag xfusion-ecr:latest 243552893788.dkr.ecr.us-east-1.amazonaws.com/xfusion-ecr:latest
docker push 243552893788.dkr.ecr.us-east-1.amazonaws.com/xfusion-ecr:latest
```
