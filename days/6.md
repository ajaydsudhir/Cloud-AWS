## Solution
1. Log in to the AWS Management Console using the provided credentials.
2. Navigate to the EC2 service.
3. Click on "Launch Instance" to start the instance creation process.
4. Name the instance `xfusion-ec2`.
5. Select the `Amazon Linux AMI` from the list of available AMIs.
6. Choose the instance type `t2.micro` and click "Next: Configure Instance Details".
7. Create a new RSA key pair named `xfusion-kp` and download the private key file.
8. Attach the default security group to the instance.
9. Review the instance configuration and click "Launch" to create the EC2 instance.
