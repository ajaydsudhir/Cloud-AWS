## Task

The team is in the process of setting up an EKS cluster that meets their internal security and scalability standards. ## Solution
1. Login to the AWS Management Console using the provided credentials.
2. Navigate to the Amazon EKS service in the `us-east-1` region.
3. Create a new EKS cluster with the following configurations:
      - Configuration type: Custom 
      - EKS Auto Mode: Disabled
      - Cluster name: `nautilus-eks`
      - Cluster IAM role: `eksClusterRole` (Create this role with the necessary permissions for EKS)
      - Kubernetes version: `1.30`
      - VPC: Default VPC
      - Subnets: Select subnets in availability zones `a`, `b`, and `c`
      - Endpoint access: Private
      - AWS Add-ons: Remove `Pod Idetity Agent` and `Node Monitoring Agent`
      - Community Add-ons: Remove `External DNS` and `Metrics Server`
4. Wait for the cluster to be created and verify that it is in the `Active` state.
