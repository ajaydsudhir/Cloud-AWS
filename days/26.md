## Solution
1. Log in to the AWS Management Console using the provided credentials.
2. Navigate to the EC2 service in the `us-east-1` region.
3. Create a new EC2 instance with the following specifications:
   - **AMI:** Ubuntu AMI
   - **Instance Type:** t2.micro
   - **Security Group:** Allow SSH, HTTPS, and HTTP traffic from the internet.
4. Under the "Advanced Details" section, add the following user data script to install and start Nginx:
```bash
#!/bin/bash
sudo apt update -y
sudo apt install nginx -y
sudo systemctl start nginx
sudo systemctl enable nginx
```
5. Launch the instance.
6. Verify that the instance is running and accessible by navigating to its public IP address in a web browser.
